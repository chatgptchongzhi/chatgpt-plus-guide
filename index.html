FAQ

ChatGPT Plus 是否包含 API 额度？

不包含。ChatGPT 订阅与 OpenAI API 使用不同的计费体系。

已有 Plus 可以马上再次充值吗？

请以商品说明为准。为避免剩余时间无法叠加，通常建议当前会员到期后再操作。

卡密在哪里使用？

按照商品订单中提供的充值页面和最新教程操作，不要在不明网站提交敏感信息。

充值完成后在哪里确认？

刷新 ChatGPT，进入账户的套餐或订阅页面查看当前会员状态。
