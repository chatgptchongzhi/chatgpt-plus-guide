# 石榴清单 Windows 更新

1.1.0 增加「检查更新」入口，应用自行下载签名更新包，用户确认后关闭应用、替换程序文件并重启。个人任务保存在原 userData 目录中，不随程序文件替换。

latest.json 是 Ed25519 签名信封，包含 payload 和 signature。客户端内置公钥，验证签名、平台、Electron 运行时版本、文件大小和 SHA-256。私钥只保存在本地，不得上传。

新发布需要提高三段式版本号，生成新的 app.asar 和签名 manifest，并以新文件名与 latest.json 一起提交。保留旧更新文件。当前更新方式支持相同 Electron 45.2.3 运行时下的应用功能更新；升级 Electron 运行时需要另行发布完整桌面包。更新需要 GitHub 网络可达和程序目录写入权限。

测试覆盖版本比较、签名篡改、包校验、文件替换及损坏包拒绝。尚未完成实际桌面界面的更新重启测试。
